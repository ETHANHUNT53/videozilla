# F3.4 — Instagram caption + hashtags panel

**Status:** design **approved 2026-10-21** ([answers](#your-answers-2026-10-21): rewrite counts 1 revision, Edit → Save / Cancel, Instagram's limits with 5–15 as a hint, cover text shown and editable). Being built.

**Sources:** PRD F3-FR4 (caption ≤ 2,200 characters, hashtags 5–15 and at most 30, a suggested cover text), §5.1 (Indian and global education hashtags), §13.1 task T8 (caption and hashtags, `llm.fast`), §13.5 (`update_social` is a revision operation), §17 (Instagram: caption ≤ 2,200, ≤ 30 hashtags, ≤ 20 mentions), F9-FR5 (the publish dialog pre-fills this caption later); API Design §7.2 (`422 CAPTION_INVALID`), §13.4 (each manual edit creates a storyboard version); DB Design §4.6 (`source: manual_edit`), §6.3; Stitch screen 10 (the "// instagram caption" card); built on F3.1–F3.3 (the storyboard's `social`, versions, the review screen).

## What you'll see

The read-only caption under the scenes (F3.3) becomes the **Instagram panel** (Stitch 10's card, with editing added):

1. **// instagram caption** with **Copy** (copies the caption and the hashtags exactly as they'll be posted), **Edit** and **✨ Rewrite with AI** (Q1).
2. The caption text, the hashtags as chips, the **cover text** ("on the cover: …", Q4), and the counters: `182 / 2,200 characters` (caption plus hashtags, as Instagram counts them) and `8 / 30 hashtags`, with a hint when there are fewer than 5 or more than 15.
3. **Edit** (Q2) turns the card into a form:
   - the caption in a growing text box with its live counter;
   - the hashtags as removable chips plus an "add hashtag" box (Enter or comma adds; `#` is added for you; spaces are removed; duplicates are ignored; Hindi tags such as `#विज्ञान` work);
   - the cover text (one line, at most 5 words);
   - **Save** / **Cancel**. Over a limit, Save is off and the counter says why (no silent cutting).
4. **✨ Rewrite with AI** writes a new caption, hashtags and cover text for this storyboard in the video's language (an optional instruction such as "more fun, fewer emoji"), shown in place, then saved like an edit. "Thinking…" while it runs; the usual busy / limit / refused messages.
5. Every saved change makes a **new storyboard version** ("Edited the caption" / "Rewrote the caption with AI"), so F3.5's history can show and undo it; the scenes don't change and nothing is rebuilt.

## API

### `PATCH /api/v1/projects/{id}/storyboard/social` → `201 StoryboardVersion`

- **Body** (strict, at least one): `{ caption?, hashtags?, coverText? }`, with **`If-Match: "<currentStoryboardVersion>"`** (required).
- **Rules** (one function shared by the page, the API and the AI path):
  - `caption`: trimmed; no control characters except new lines; at most 2,200 characters (counted as Instagram does, in characters, so Hindi and emoji count as one each).
  - `hashtags`: 0–30 items; each normalised (`#` added, spaces and extra `#` removed), then `#` + letters, marks (Devanagari matras), digits or `_`, at most 100 characters; duplicates (ignoring case) dropped.
  - **Together** (what will be posted: caption + blank line + hashtags): at most 2,200 characters, at most **30 hashtags** counting any inside the caption, at most **20 @mentions**. Otherwise `422 CAPTION_INVALID` with `details` saying which limit.
  - `coverText`: one line, 1–40 characters, at most 5 words.
- **Saves a new version** in one transaction (DB §6.3): the current storyboard with only `social` changed, `version + 1`, `source: "manual_edit"`, `basedOnVersion` = the current one, `changeSummary` "Edited the caption" (or "…the hashtags" / "…the cover text"), `changedSceneIds: []`; the project's `currentStoryboardVersion` moves, its status stays `storyboard_ready`. Newest 30 versions kept, as now. A save that changes nothing returns the current version (`200`), with no new version.
- **Errors:** `404`, `409 INVALID_STATE` outside `storyboard_ready` (generating, later building), `412 PRECONDITION_FAILED` when the storyboard changed meanwhile (a regenerate or another tab) with the current version in `details.current` (the page shows the stale-tab line and reloads), a missing `If-Match` → `400`, `400` / `422` as above.

### `POST /api/v1/projects/{id}/storyboard/social/rewrite` → `200 { social }`

- **Body:** `{ instruction?: string (≤ 300 chars) }`.
- **AI (T8):** `generateJson` with the provider chain, `llm.fast`, 15 s, temperature 0.8; logged in `ai_calls` as task `caption`. The prompt gets the storyboard's title, hook, the scenes' headlines and on-screen text (not every word of narration), the language, audience and board, and the instruction, all as data; it returns `{ caption, hashtags, coverText }` or a refusal, checked by the same rules (one repair round). Indian + global education hashtags, 8–12 of them, in the video's language and script (Hindi captions in Devanagari; hashtags may mix `#विज्ञान` and `#ScienceFacts`).
- **Not saved by itself:** the page shows the result in the edit form, and **Save** stores it through the `PATCH` (so a rewrite you don't like costs nothing in history). The limit unit is counted on the rewrite (Q1), refunded when nothing usable came back.
- **Mock (`AI_PROVIDER=mock`):** a sample from the storyboard's title, in its language, marked "[Mock]"; `[mock:busy]` / `[mock:refuse]` in the instruction trigger those paths.
- **Errors:** as the idea AI: `422 UNSAFE_CONTENT`, `429 LIMIT_REACHED`, `503 AI_BUSY`, `409` outside `storyboard_ready`, `404`.

## Where the data lives

`social` is already part of every storyboard version (F3.1 generates it; the validator cleans hashtags and caps the caption). Nothing new in the database; no migration. `ai_calls.task` gains `caption` (the field has no validator).

## The page (`components/social-panel.tsx`)

- Replaces the F3.3 placeholder card; same place under the scenes (Stitch 10).
- Copy uses the clipboard API with a "Copied" confirmation (and a fallback that selects the text).
- After a save, the page shows the new version (version chip `Version N+1`) without a reload; the scenes stay as they are.
- Accessibility: the counters are announced when a limit is passed (polite); chips have "Remove #science" buttons; the form keeps focus order caption → hashtags → cover text → Save.
- Phone (360 px): the panel is full width; chips wrap; no sideways scroll.
