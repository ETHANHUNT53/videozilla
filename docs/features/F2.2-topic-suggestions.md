# F2.2 — Find a topic → 5 AI idea cards

**Sources:** [M2 design §2, §4](../M2_DESIGN.md) (approved, with Q2: an `ideas` limit of 150/day), PRD F2-FR2 / §20.6 / §21, API Design §13.3, System Design §8, DB Design §4.4 / §4.16 / §4.17.

## What you'll see

In the Idea step's **Find a topic** tab:
1. Type a subject or niche, press **Suggest 5 ideas**.
2. Within a few seconds, 5 idea cards appear. Each card has a title, a one-line hook, the angle, and 3 key points.
3. On each card:
   - **More like this** asks for 5 ideas close to that card;
   - **Use this** turns the card into a brief. That's F2.3, so it stays disabled for now (scope stops after F2.2).
4. Under the cards, **Suggest 5 more** asks for 5 new ones on the same topic; Gemini is told every title already shown and asked for new concepts (it usually complies; one early run reworded a card, so the instruction was tightened).
5. The cards are saved with the video, so they're still there after a reload.

## API: `POST /api/v1/projects/{id}/idea/suggestions`

**Request:**
- **Body:** `{ topic, audience?, avoidTitles? }`, strict:
  - `topic` 1–200 characters;
  - `audience` one of the four audience levels (defaults to the video's);
  - `avoidTitles` up to 30 titles of up to 120 characters.
- **Allowed** while the video allows `edit_idea` (`idea_draft`, `storyboard_ready`); otherwise `409 INVALID_STATE`.

**Response:** `200 { suggestions: [5 × { id, title, hook, angle, keyPoints[3] }] }`.
- The new cards are added to the idea session's `suggestions`, keeping the newest 30.
- This doesn't change the idea's `rev`: `rev` guards what you type, so a suggestion run never makes the next autosave look like a conflict.

**Errors:**

| When | Answer |
|---|---|
| Today's `ideas` limit is reached | `429 LIMIT_REACHED` + `Retry-After` |
| Gemini still busy after the retries and the fallback model | `503 AI_BUSY` + `Retry-After` |
| A prohibited topic (PRD §21.1) | `422 UNSAFE_CONTENT` with a plain message |
| Unknown or someone else's video | `404`, like everywhere |

**Limit:** one new shared counter, `ideas` (default **150 per day**, IST). It covers idea suggestions now, and briefs and idea chat when they arrive. It's counted **before** the Gemini call, in the same check-and-count step as the other limits, and isn't given back if the call fails.

## AI call

A small shared helper in `packages/ai`, `generateJson`, used by all the idea features:
- **Model:** `GEMINI_FAST_MODEL` (default `gemini-3.8-flash`, with thinking set to LOW), with one quick retry when it's busy, then `GEMINI_FALLBACK_MODEL` (`gemini-3.5-flash-lite`).
- **Time:** the whole thing stays within **15 s**; past that, `AI_BUSY`. The main model gets the budget minus 4 s, which are always kept for the fallback. A main model that timed out isn't tried again.
- **Measured on the free tier** (5 Hindi cards), which is why the time is split like this:

  | Model | Setting | Time |
  |---|---|---|
  | `gemini-3.8-flash` | default thinking (~1,100 thought tokens) | ~15 s, too slow |
  | `gemini-3.8-flash` | thinking LOW | 8–12 s |
  | `gemini-3.5-flash-lite` | — | ~2 s |

  The UI says "usually about 10 seconds". The paid tier (System Design Q9) should be faster.
- **Checking:** the reply must be JSON matching a Zod schema; on a mismatch Gemini gets the errors and one chance to fix them.
- **Logging:** each call is logged in `ai_calls`: task `ideas`, model, tokens, latency, outcome.

**Prompt:**
- **Inputs:** the topic, audience, board or exam, the video's language (Hindi → natural Hindi in Devanagari), and the creator's "what I teach or create about" (F1.12).
- **Data, not instructions:** the topic and titles are wrapped in tags and marked as data, never instructions (prompt-injection hygiene).
- **Prohibited topics** (PRD §21.1) return `{ "refused": true, "reason": … }` → `422`.
- **Sensitive-but-allowed topics** (health, finance, law…, §21.2) are kept general-education and conservative.
- **Every idea must fit a 60–90-second explainer**, with exactly 3 key points.

## Small fixes from QA on the Idea step (F2.1)

1. **Accessible names:** each text box's label is only its title; the hint and counter are linked by `aria-describedby` instead of being inside the label.
2. **Conflict bar placement:** the "changed in another tab" bar sits above the text box, so it's visible on a phone.
3. **Disabled buttons look disabled:** a muted outline instead of faded cyan.
4. **Documented, not changed:** a save with a stale `If-Match` answers `412` even if the text happens to be the same. The precondition is checked first, as HTTP specifies, and the "Load latest / Keep mine" bar handles it.
5. **No change:** switching tabs saves after the usual 800 ms (or at once when the browser tab is hidden), as designed.

## Tests

- **Endpoint:**
  - the 5 cards and their shape; saving them (newest 30) without a `rev` change;
  - `avoidTitles` and audience in the prompt;
  - topic and notes kept as delimited data;
  - limits; the strict body; status rules;
  - `404`, plus cross-user cases.
- **Errors:** `429` with nothing sent to Gemini, `422` on refusal, `503` on busy.
- **`generateJson`:** busy retry then fallback, the 15 s deadline, the repair round, invalid JSON.
- **Browser:** real Gemini runs (free tier) on a Hindi video:
  - first ask: an "aborted" timeout, which led to the timing fix above;
  - after the fix: 5 Hindi cards in 7.8 s, fitting the video's College / NEET settings;
  - **More like this** and **Suggest 5 more** gave 15 unique titles, still there after a reload;
  - a weapons topic: `422`, with the reason in Hindi;
  - the cards use one column when the space is narrow.

## Review fixes (after 6864423)

- **Refund:** the `ideas` count is still taken before the Gemini call, but it is given back (`refundUsage`, never below zero, same IST day) when nothing is delivered: AI busy after the deadline, an unusable reply, or another error. Refusals and safety blocks still count.
- **Safety blocks:** a prompt or reply blocked by Gemini's own filters (`promptFeedback.blockReason`, or a `SAFETY` / `PROHIBITED_CONTENT` / … finish reason) raises `AiBlockedError` at once, with no repair round, no retry and no fallback. The route answers it like a refusal: `422 UNSAFE_CONTENT`.
- **Prompt safety:** user text (topic, avoided titles, the profile's "about") has its angle brackets replaced with look-alikes (‹ ›), so no tag variant can close a data block early.
- **Stage changed meanwhile:** `addSuggestions` checks `edit_idea` again after the call; if the video moved on (e.g. a storyboard started), nothing is saved and the answer is `409`.
- **Double-click:** "Suggest 5 ideas", "Suggest 5 more" and "More like this" send one request per click (ref guard), since each costs a Gemini call.
- **Key:** checked after a production build: the Gemini key and `GEMINI_API_KEY` appear in no client file, and `.env.local` is git-ignored.
